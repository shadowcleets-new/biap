# Project Brief: BIApp (Business Intelligence App)

## 1. Executive Summary
BIApp is a native Android Business Intelligence application designed to provide rich data visualizations, reports, and analytical insights. All features are baked on-demand as directed by the user.

## 2. Architectural Overview
- **Platform:** Native Android (Kotlin)
- **UI Framework:** Jetpack Compose
- **Build System:** Gradle (Kotlin DSL, AGP 9)
- **Minimum SDK:** Android 24+ (or as defined by template)
- **Target SDK:** Android 34/35/36
